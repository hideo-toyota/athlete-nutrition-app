# 2026-07-17 考察 — 胸椎が「前傾」と「肩」の共通の親か（H-B格上げ）

#pitching/daily #pitching/highlight

## 仮説（本人発）
- **胸椎が使えない → 前傾が作れない → 肩を過度に使っている**のでは？

## 評価：生体力学的に成立。上流の共通原因の最有力候補
連鎖：
```
胸椎(伸展/回旋)不足
 ├→ 前傾が作れない（前傾は胸椎伸展＋股関節の上で起きる。硬いと腰椎/腕で代償）
 └→ 肩甲骨が胸郭(=胸椎で形が決まる肋骨のカゴ)の上に乗れない
      → 肩甲骨が上方回旋/後傾できず、肩関節だけで無理に上げる=インピンジ
 ⇒ 生み出せない仕事を肩(腕)が穴埋め=肩の過使用→後方の凝り・出力低下
```

## 全症状が1本に束ねられる
- 肩の過使用/インピンジ/後方凝り … 肩甲骨が胸郭に乗れず肩関節が代償 ◎
- 前傾が作れない・突っ込む … 胸椎伸展/回旋不足 ◎
- 投球中の胸椎(背中中央)の痛み … 動かない胸椎に負荷集中 ◎
- 「肩甲骨・鎖骨の動きが悪い」感覚 … まさに肩甲胸郭=胸椎上の問題 ◎
- 「肩裏を入れると腕が上がる」体験 … 肩甲骨安定で改善＝土台問題と整合 ◎

## 正確な位置づけ
- 今季の直接の引き金は**足首(下半身駆動の喪失)**。胸椎は「単独犯」でなく**代償の逃げ道を塞ぎ、肩への集中を増幅する因子**。
- ＝胸椎は「共犯者・増幅器」。ただし**元々の最優先課題 H-B そのもの**。今回、H-Bがフォーム効率だけでなく**傷害発生**の中心でもあると実証。

## アクション（プラン格上げ）
- **胸椎伸展・回旋モビリティを、下半身再建と並行して毎日の中心課題に格上げ**（従来は補助的位置づけ）。
- 土台(胸椎)が動く→肩甲骨が乗る→肩代償減＋前傾が戻る＝一石三鳥のレバー。
- 専門医/整骨院で**胸椎の可動性(伸展・回旋)を明示的に評価**依頼。
- 月次テストの thoracic_L/R（胸椎回旋ROM）を再建の主要KPIに。
