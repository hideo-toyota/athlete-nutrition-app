# 大会へ向けたプラン（痛みゲート式・段階的投球）

- 作成: 2026-06-29 / **大会本番: 7/11（Day12）**／持ち時間 **12日間**（想定より2日短くタイト）／**役割: 先発**
- 前提: 肩前面インピンジメント（診断済・半年で改善傾向）／6-28登板後にキャッチで痛み4割・出力低下の再燃／**投球復帰は専門家と未相談**。
- 本プランは医療行為の指示ではない。**今週中に専門医へ「2週間後の投球可否・進め方」を相談し、その指示が出たら本プランを差し替える**前提の"安全側の雛形"。

## 0. 大原則（これだけは守る）
1. **ゴール＝「痛みなく、限定的な役割で投げられる」**。球速・イニング数は二の次。
2. **痛みゲート**：投球中の痛み **≤2-3/10** かつ **投げ終わると速やかに引く** 範囲でのみ実施。超えたら**その日は中止し、次段階へ進めない**。
3. **球速を物差しにしない**（回復期は球速が最後に戻る）。出力でなく「痛みなく投げ切れたか」で判断。
4. **投球日と回復日を交互に**。連投・連続ブルペンはしない。
5. 下記の**レッドフラグが出たら即中止し受診**：鋭い痛み／安静時・夜間痛／腕が上がらない／しびれ・脱力。

## 1. 毎日の土台（throwing有無に関わらず）
- **可動域ケア（朝＋投球前）**：肩甲骨・胸椎モビリティ＋後方カフ。インピンジメントのスペースを確保する方向（内容は専門家と確認）。日次 `thoracic_drill: true`。
- **睡眠 7-8h を最優先**（直近5h47m・レム不足は回復の足かせ＝H-J/H-A）。
- **投球前ルーティン**：軽い有酸素→可動域→軽いキャッチで段階的に上げる。痛みの出る角度を確認しながら。
- 投げた日は `throwing` ログに **痛み％・球数・距離・強度** を記録。

## 3. GO/NO-GO 判定基準（役割の決め方）
- **判定A(Day3 / 7/2)**: キャッチで痛み≤2＆すぐ引く → 続行。痛み>3が続く → 計画を遅らせ、大会は**回避 or 超限定**を前提に。
- **判定B(Day6 / 7/5)**: 75%フラットが痛み≤2-3 → ブルペンへ。不可 → ブルペン段階を1つ落とす。
- **判定C(Day10 / 7/9)**: 実戦想定ブルペンの結果で大会の役割を確定（本番2日前）。**役割＝先発**前提の球数上限：
  - 痛みなく85-90%・30球OK → **先発可。ただし球数上限 50-65球 / 3-4回を厳守**（届かなくても切る）。1巡目から無理に出力を上げない。
  - 痛みは軽いが出力上がらず → **先発でも短く（2-3回 / 40球上限）**、早めの継投前提。
  - 痛み>3 or 出力に明確なフタ → **先発回避**（リリーフ1回限定 or 今大会は投げない）。半年の回復を1試合で棒に振らない。
  - いずれも**本番中に痛みが3を超えたら即降板**。球数より痛みが上位基準。

## 3b. ケア（治療/施術）の入れ方
- **鎮める系（軽いマッサージ・血流促進・可動域・消炎）＝投球翌日に**（炎症ピークを翌日に持ち越さない）。
- **攻める系（深い手技・強いほぐし・関節モビライゼーション・負荷リハビリ）＝投球から離れた日（中1日以上）に**。炎症直後に強くやると悪化しやすい。
- ★**本番前日(7/10)に新しい強い施術を入れない**（だるさ・出力低下が残る）。軽い流しのみ。**深い施術は大会後(7/12以降)**。
- 配置の目安：軽ケア→7/3・7/8・本番翌日(7/12) ／ 強い施術は回復日かつ次の投球まで余裕のある日に。内容が決まれば日付を確定する。

## 4. この2週間で"やらないこと"
- 痛みを押しての全力投球／球速チェックで力み比べ。
- 連投・連続ブルペン・遠投の急な距離アップ。
- 「上がらないから」と出力をさらに上げる（疼痛抑制を悪化させる）。

## 5. 記録（毎回）
- 投げた日: `throwing` ログに **pain / pain_loc / pitch_count / intensity / 距離 / 出力感**。
- 日次: 睡眠・可動域実施・肩の張り(cuff)。
- これで「どの段階で痛みが出たか」を私が追い、判定A/B/Cの材料にします。

## 6. 実績アップデート＆最終3日ガイド（7/8時点）
### 実際に起きたこと（プランと乖離）
- 段階的デロードは実施されず、**6/28・7/4 と5回登板を2試合**。中6日。
- 7/4は肩の動きが悪く出力上げられず。**肩後方の深い凝り（ズーン）が休んでも残存**、7/8時点も残る。
- 動画上メカは大きく崩れず＝**出力低下の主因は肩の状態（後方タイトネス＋防御的抑制）**。

### 大原則の再確認
- **今から本番(7/11)までは"積む"時期ではなく"回復させる"時期**。凝りは負荷でなく回復で取れる。投球量は最小限に。
- 本番はハード制限（下記）。**痛み>3 or 明確な出力ダウンで即降板**。半年の回復を1試合で棒に振らない。

### 最終3日（7/8→7/11）
| 日 | 内容 |
|---|---|
| **7/8(本日)** | **深い施術はこの日に**（本番まで中3日の緩衝）。整骨院：ハイボルテージ＋後方モビリティ/手技OK。以後ハード投球なし。 |

### ケア（整骨院）タイミングの結論
- **ハイボルテージ＝モダリティ（鎮痛・循環）**：リスク低く、**前日(7/10)でも可**。本番用の症状緩和として有効。
- **深い手技/身体的アプローチ＝前日は避ける**。**本日(7/8)に実施**し、翌日の軽いキャッチで再適応させるのが最善。深い施術直後→全力本番の直行は避ける。
- **期待値の管理**：1回の施術で"積み上がった深い凝り"は取り切れない。本番の症状緩和には役立つが、出力の全回復は望みにくい。

### 正直な注記
- 深いズーン＋出力低下が**2試合続けて**出ている＝肩が登板間に回復できていない可能性。**本番後は早めに専門医で後方タイトネス/インピンジメントを再評価**を強く推奨（できれば本番前でも）。整骨院は対症で有用だが、"なぜ取れないか"の評価は専門医の領域。

## 7. 前日アップデート（7/10）— 右足首捻挫が重複 ★リスク上昇
- 7/9練習中に**右足首（利き腕側＝軸足/駆動脚）を捻挫**。骨・靭帯異常なし、**腫れ残存（急性期）**。
- 肩：モビリティ60%・違和感（痛みではない）・全身が使えず出力の割に球速出ず＝守り継続。

### 重複リスクの構造
- **軸足捻挫→蹴り出せない→下半身が使えない→弱っている肩に負担集中**。足首を庇うほど肩を悪化させる最悪の連鎖。

### 前日(7/10)の過ごし方
- 足首：**RICE**（安静・アイシング15-20分×複数回・圧迫・挙上）。痛みの出ない範囲の足首ROMのみ。マウンドでの強い投球なし。明日用にテーピング/ブレース準備。
- 肩：軽いモダリティのみ（ハイボルテージ/軽い流しOK、**新規の深い手技NG**）。出力追わない。
- 全体：睡眠最優先・水分/栄養・道具準備。

### 明朝(7/11)GO/NO-GO（足首・痛みなくクリアで初めて可）
1. 歩行/軽ジョグ痛みなし → 2. 右片脚立ち安定 → 3. 右カーフレイズ（蹴り出し）痛みなし → 4. ホップ＆着地痛みなし → 5. W-up投球でプレート蹴り出し時に痛み/動きの変化なし。
- **1つでも不合格なら投げない or 超限定**。投げる場合も**短いイニング/球数厳守・痛みor蹴り出し不良で即降板**。
- 予選は重要だが、**急性足首捻挫＋守りの肩で全力5回は、足首再受傷＋肩後退を同時に招く**。限定・回避も本気の選択肢。
