# CLAIMS — 主張の監査規約(もっともらしさを信用しない)

分析出力(market-pulse / equity-analysis / 各レポート)は、**主張を分類タグ付き**で提示する。
目的:整った文章を鵜呑みにせず、**すべての主張を監査可能に分解**する(原則3)。

## 分類
- **FACT**: ソース/入力ファイルで直接確認できる(**出典 + as_of/retrieved_at 必須**)
- **CALCULATION**: コードの計算結果(どの計算か明示。入力の as_of に依存)
- **INFERENCE**: 事実からの推論(前提を明示)
- **ASSUMPTION**: 明示された仮定(手入力概算・パラメータ・シナリオ前提)
- **UNKNOWN**: 根拠不足(正直に「分からない/未取得」と言う)
- **UNSAFE**: 売買断定・未来予測・根拠なき推奨 → **出力禁止**

## 鉄則
- 出典/as_of の無い **市況・業績・価格** を FACT 扱いしない → UNKNOWN か、取得して FACT 化。
- **最新情報を見たふりをしない**(retrieved_at が無ければ「未取得」と明示)。
- CALCULATION が手入力概算(`indices/*.json` 等)に依存するなら **ASSUMPTION依存**と明記。
- 「買うべき/売るべき」「上がる/下がる」は **UNSAFE**。分類ラベル(買い候補等)は出発点であり指示ではない。
- INFERENCE と FACT を混ぜない(因果の「→」は推論として分離・前提明示)。

## 各主張に付ける監査項目(claim-auditor の出力形式)
主張 / 分類 / 根拠(file:line または source) / as_of・retrieved_at / 反証可能性 / 誤解リスク / 修正表現
