# Target Check — 10x Feasibility & Ruin Guard

_目標 10倍 / 7年 / 現資産 8,000,000円 / 月次積立 250,000円 / 課税割合 90%_

## まず:これは何か(不確実性)
- これは**目標の難易度とリスクの可視化**。**投資助言でも予測でもなく、銘柄も出しません。**
- リターンは**予測不能**。以下は「仮定の下での算術(CALCULATION)」。指数の歴史値は参考(ASSUMPTION)。

## 必要リターン [CALCULATION]
- 必要CAGR(税前): **38.9%/年**
- 税引後 10倍に必要な税前倍率: **12.01倍** → 必要CAGR(税考慮): **42.6%/年**(NISA分は非課税で軽くなる)
- 月次積立込みの必要CAGR: **26.9%/年** (現資産だけなら 42.6%/年)。**10xの多くは“貯蓄×時間”で来る**。

## ★混合の現実(コア/サテライト)[CALCULATION]
- 現配分 コア90% / サテライト10% では:
  - サテライトが 5倍・コア横ばい → **全体 ≈ 1.40倍**
  - サテライトが 10倍・コア横ばい → **全体 ≈ 1.90倍**
  - サテライトが 20倍・コア横ばい → **全体 ≈ 2.90倍**
- 全体を 10倍にするには、サテライト10倍でも **コアが 10.0倍** 必要(=指数では非現実的)。
- → **10%枠のサテライトだけでは、原理的に全体10xは届かない。**

## 破綻・回復ライン [WARNING]
- サテライト全損時の総資産インパクト: **-10.0%**
- ドローダウンからの必要回復率: -20%→+25% / -30%→+43% / -50%→+100% / -70%→+233%
- 許容DD 40% を使い切ると、回復に **+67%** 必要。
- ⚠️ レバレッジ 2.0倍 → 約 **-50% の下落で資本毀損(破綻ライン)**。

## 必要条件(満たさないと到達しない)[INFERENCE]
- 42.6%/年 を7年継続(税考慮)。分散インデックスの歴史的レンジでは通常困難。
- 全体を動かすには、サテライト比率を上げる=集中とドローダウンを受け入れる覚悟。
- 不足分は「銘柄選択の超過リターン」より「貯蓄・時間・事業/人的資本」で埋める方が現実的。

## 破綻条件(これに触れたら危険)[WARNING]
- 生活防衛資金を分離していない / レバレッジで破綻ラインが浅い / 1銘柄・1セクターに上限超で集中。
- 価格下落での狼狽売り、上限を超えるナンピン(=`check` が止める対象)。

## 規律との両立(所見)[INFERENCE]
- 「余剰資金・現物・分散・上限(2.5%/5%/10%)」を守る範囲では、**純粋な銘柄選択での10xは極めて不利**。目標を持つなら、必要年率と破綻幾何を直視した上で、サイズと撤退を先に決めること。
