# 改善点対応と今後の記録ルール

作業日: 2026-06-26

## 今日確定・対応した改善点

### セキュリティ / 秘密情報
- J-Quants REST client の直接 `urlopen` 経路を見直し、`sources/live.py` の HTTP client に寄せた。
- `JQUANTS_REFRESH_TOKEN` / `JQUANTS_MAILADDRESS` / `JQUANTS_PASSWORD` / `JQUANTS_ID_TOKEN` を secret redaction 対象に追加。
- dict repr / header / Authorization / URL query のredact漏れを塞いだ。
- J-Quants raw取得・feature生成・REST fetch の入口に `tos_personal_use_confirmed` gate を追加。

### 原則 / 再現性 / PIT
- `score --asof` を必須化し、採点に実行日の wall-clock が混ざらないようにした。
- `mirror` は `--asof` 未指定時に `portfolio.as_of` を基準にし、実行日依存を排除した。
- index `as_of` が portfolio `as_of` より未来の場合は警告ではなく停止するようにした。
- `composition_ref` は `indices/` 配下のみ許可し、path traversal を拒否するようにした。
- J-Quants derived に `config_hash` / `code_commit` / REST payload hash を追加し、監査再現性を上げた。

### 正直な出力
- NaN / Inf を `nan%` / `inf JPY` として出さず、`UNKNOWN` に倒すようにした。
- research / evidence / audit-report / investor-brief / llm-handoff の表示ヘルパを整理。
- 禁止語ゲートを強化し、`BUY` / `target price` / `rank` / `目標株価` / `推奨` / `割安ランキング` などを検出するようにした。

### テスト

  - 上限超過、過熱フラグ、ナンピン3条件、免責文、買い候補語不在を確認。
- `tests/test_concentration.py` を追加。
  - look-through 合算、未来 index 停止、composition_ref traversal拒否を確認。

## 今後の記録ルール

今後はユーザーから明示されなくても、以下のどれかに該当する作業をしたら `outputs/obsidian/` に記録する。

- 設計判断を変えた。
- コード修正・テスト追加・重要な検証を行った。
- データ取得/feature生成/daily-update など運用上の状態が変わった。
- GO/NO-GO 判定、ToS/安全ゲート、投資原則に関わる判断をした。
- 未完了タスク・次の一手が変わった。

記録には、少なくとも以下を書く。

- 日付
- 何をしたか
- なぜ必要だったか
- 検証結果
- 残課題
- 投資助言ではないこと、売買判断は人間が行うこと

## 注意

APIキー、token、`.env` の値、個別口座の精緻な実額は記録しない。
raw本文や再配布に当たるデータも Obsidian には貼らない。
