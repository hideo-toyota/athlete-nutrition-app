# CLAUDE_HANDOFF — スイング紙上トライアル(swing_paper_trial)

積立(コア)とは別に、スイングトレードの裁量が**期待値プラスか**を検証する bounded experiment。
これは訓練と検証であり、売買推奨・利益保証ではない。**Phase 0 は全て紙上(paper)**。

## 前提(正直な制約)
- 現有データは日足確定(T+1)+株探観測3スロット。**デイトレは支援対象外**(リアルタイム
  ティック無し。分足判断が必要な手法はこの実験の範囲外と明記する)。
- 対象はスイング(想定保有 2〜15営業日)。
- ベースレート: 個人の短期売買の多数派は指数に負ける(研究で一貫)。この実験の目的は
  「勝てるはず」の証明ではなく「**自分は勝てる側か否かの判定**」。負けと判明したら
  それは検証の成功(=コア積立に集中するという答え)。

## Phase 0: 紙上30トレード(実弾なし)
- 期間: 30トレード完了 or 3ヶ月の早い方。
- 仮想元本: 1,000,000円(固定・複利させない)。
- **1トレードのリスク上限: 仮想元本の1%(=10,000円)**。
  サイズ = 10,000円 ÷ (エントリー価格 − 損切り価格)。

## 事前登録(エントリー前に journal/swing_paper_log.jsonl へ追記。後から編集禁止)
```json
{"id":"...","registered_at":"...","code":"6920","direction":"long",
 "setup":"vwap_reclaim_after_pullback","entry":123.0,"stop":118.0,
 "target":133.0,"time_stop_days":10,
 "thesis":"半導体テーマ内の押し目からのVWAP回復。出来高継続が条件",
 "falsification":"終値でstop割れ or 3日連続で出来高が20日平均の70%未満",
 "risk_yen":10000,"size":2000,"claim":"INFERENCE",
 "status":"open"}
```
- setup は語彙を固定(例: vwap_reclaim / range_break / pullback_in_trend / overheat_fade)。
  **後で「どの setup に期待値があるか」を分解するため**。
- 損切り(stop)=仮説の反証点。**建てた後の変更は違反として記録**(変更禁止ではなく、violation カウント)。

## クローズ時(exit を追記)
```json
{"id":"...","closed_at":"...","exit":128.0,"exit_reason":"target|stop|time_stop|manual",
 "r_multiple":1.0,"rule_violations":["stop引き下げ"],"note":"..."}
```
- r_multiple = (exit − entry) / (entry − stop)。manual exit は理由必須。

## 週次採点(scoring)
- 期待値 = 勝率 × 平均勝ちR − 敗率 × 平均負けR(単位はR)
- 併記: 累積R / 最大ドローダウン(R) / setup別の期待値 / **rule violation率**
- 同期間の対DCA(日経225 or TOPIX への同額積立)を必ず併記。
- 10トレード未満での結論は禁止(sample_too_small)。

## Phase 1 への昇格条件(実弾・全て満たした場合のみ)
1. 30トレード完了、**模擬コスト控除後**(往復0.2%を仮定)の期待値 > 0
2. rule violation率 < 10%
3. 最大ドローダウンが −10R 以内
4. 昇格しても実弾はポートフォリオの **5%以内**から。コア積立には触れない。
- 満たさない場合: 実験終了 or Phase 0 をもう1周(判断は人間)。**基準の緩和は禁止**。

## 鉄の掟(この実験内)
- ナンピン禁止(1仮説1エントリー)。stop は動かさない(動かしたら violation)。
- 同時オープンは最大2件(初期)。信用・レバレッジ禁止。
- 「ニュースで飛び乗り」禁止: エントリーは**事前登録済み setup に一致**した時のみ。
- split_artifact_warning やデータ差のある銘柄は対象外。
- 実弾フェーズでも自動売買はしない(このシステムの恒久ルール)。

## 教育との連動
- daily-education のカリキュラムに **G-トレード規律**(R倍数/期待値/損切り=反証/サイズ/記録)を追加。
- 週次採点の結果は education ledger と同様に、成績が悪くても正直に記録する。
