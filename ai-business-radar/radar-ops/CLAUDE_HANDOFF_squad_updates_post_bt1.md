## 全班共通の前提(BT-1 全期間トレインの評決・2026-07-05)
- 3つの価格系setup(押し目/ブレイク/過熱フェード)は**17年検証でエッジ無し・取引候補クローズ**。
- データで裏付けられた**防御ルール3つ**が収穫物:
  ①過熱(20日+40%超)銘柄をロングで追わない ②リスク1%/トレード ③決算を跨がない
- **主戦場は中期レーン(value-audit 決算to決算)へ移行**。各班の任務の重心もこれに合わせる。
- 規律は不変: 売買推奨・ランキング・価格目標なし / FACT・INFERENCE分離 / 本文非保存 /
  APIキー・raw本文非表示 / 出典+as_of必須。

## 班1: J-Quants 分析班
**任務の重心変更: 「シグナル探索」→「中期レーンの計測インフラ+防御ルールの計測係」**
1. 日次観測に overheat_flag(return_20d >= +40%、閾値はconfig)を標準搭載。
   該当銘柄への固定文言: 「過熱: 追随エントリーはBT-1検証で期待値マイナス。検証入口のみ」
2. 次の実装優先は DT-1: ①決算発表予定(将来分)→②信用残(週次)→③空売り比率。
   取得は既存規律(raw+provenance+PIT+tos_personal_use_confirmed)で。
3. value-audit 用の PIT価格系列・PER/PBR提供を主任務に昇格(中期レーンの土台)。
4. やらないこと: 新しい価格系シグナルの独自探索(setup追加は事前登録制・司令塔経由のみ)。

## 班2: 株探(kabutan)分析班
**解釈の転換: 「盛り上がり=入口候補」→「盛り上がり=過熱確認の対象」**
1. trigger_families の rising_stocks / popular_theme_3d 該当銘柄は、
   J-Quants班の overheat_flag と突合し、該当時は「過熱注意」を必ず併記。
2. 出力文面から「追随を誘う枠組み」を排除(「勢いが強い」単独表記は禁止。
   必ず「過熱・出来高継続・剥落リスクの確認対象」の形にする)。
3. 観測3スロット・メタデータのみ・本文非保存の既存規律は不変。
4. 新任務: テーマの過熱が「何日続いて剥落したか」の事後記録(防御ルールの較正データ)。

## 班3: 日経分析班
**任務の重心変更: 「市況ダイジェスト」→「中期レーンへのイベント供給」**
1. event_type 抽出を強化: 「決算関連(上方/下方修正・進捗)」「構造変化(増産・提携・
   規制・値上げ)」を最優先タグに。これらは value-audit 候補の入口として司令塔へ。
2. 決算日程への言及を検出したら、earnings calendar(DT-1)との照合メモを付ける
   (カレンダー未実装の間は「照合不可(UNKNOWN)」と正直に)。
3. 「高値警戒」系記事は overheat_flag との独立一致として記録(SG-1合流の材料)。
4. 記事本文非保存・出典URL+as_of必須の既存規律は不変。

## 班4: NewsPicks 解析班
**位置づけの明確化: narrative attention = 混雑度(crowding)の代理指標**
1. attention の高低は「注目の事実」であり、良し悪しの判断材料にしない(INFERENCE固定)。
2. 新タグ: attention高 × overheat_flag該当 = 「二重過熱」。観測メモとして記録
   (SG-1合流の先行運用。ただし出力は観測まで、行動指示にしない)。
3. コメント・本文の非保存、メタデータのみの既存規律は不変。
4. 較正課題: 「二重過熱」タグ銘柄のその後20日リターンを月次で集計(タグが意味を
   持つかの検証。持たなければタグ廃止を司令塔に具申)。

## 班5: EDINET 分析班
**優先度昇格: 中期レーンが主戦場になったため、この班が今後の主力**
1. 最優先: financials カバレッジ拡大(現状400/3837 → 計画的に全上場へ。
   日次レート1,000/日の範囲で batch継続、失敗分の再取得管理)。
2. company_map の鮮度維持(週次更新)。
3. 最終目標: value-audit の入力を手入力ASSUMPTION から **EDINET実績のFACT/CALCULATION**
   に置き換える(7203で実証済みのフローを一般化)。
4. cross-check(EDINET×J-Quants)の mismatch 診断を継続(audit-report)。
