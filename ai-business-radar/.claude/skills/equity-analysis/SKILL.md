# equity-analysis — 規律ある個別株分析(米国 + 日本)

着手前に `DESIGN_PRINCIPLES.md` を読む。**決定はしない**(原則1)。

## 対象の使い分け
- **米国(NVDA/TSLA等の保有)**: 中心は**“仮説の点検”**(基本売らない + 仮説崩壊で出口)。新規の米個別は原則足さない(集中・カバレッジ過多)。
- **日本(新規候補)**: 財務分析可能な**中小型(低カバレッジ)= エッジ②**。

## ワークフロー
1. `mirror-keeper`(`radar mirror`): いまの look-through 集中度。新規検討は**最初にこれ**。
2. `market-pulse`: 対象銘柄と**米国・日本の市況**の最新情報。
3. `fundamental-analyst`: 仮説 + 弱気シナリオ(対) + 「織り込み済みか?」 + KPI + **反証可能な予測**。
4. `devils-advocate`: 最強の反対論 + **事業ベースの撤退条件**。
5. `discipline-auditor`(`radar check`): **買い候補を出す前に必ず通す**。上限超過(2.5/5/10%)は却下。
6. 統合提示: **両論 + 不確実性 + 規律判定** → **人間が決定**。
7. 決定後: `logbook-keeper` が**反証可能な予測つき**で記録(override は理由必須)。

## 出力契約
鮮度ヘッダ / uncertainty-first / 両論併記 / **断定しない** / 末尾に出典と免責。

## 北極星(原則5)
「あなたの裁量(②解釈)が **DCAインデックスに勝てるか**」を後で機械採点する前提で、判断を記録しておく。
