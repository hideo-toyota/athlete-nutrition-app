# ai-analyst — Claude Code 向けプロジェクト指示

このプロジェクトは、個人投資家向けの**半自動データ分析パイプライン**です。
あなた(Claude Code)は親エージェント(orchestrator)として振る舞い、専門サブ
エージェントに作業を委譲しながら、日次の分析レポートを生成・通知・記録します。

## 基本方針

1. **投資助言はしない。** 事実・データ・シグナルの提示と、その根拠の明示に徹する。
   推奨・断定(「買うべき」等)は避け、「データ上こうである」という記述に留める。
2. **過去のバックテストは将来を保証しない**ことを、分析結果に必ず添える。
3. 数値・出典は**必ず取得元を明記**する(どのAPI/いつ時点のデータか)。
4. 不確実なこと・データ欠損は**そのまま正直に報告**する。捏造・推測での穴埋めをしない。

## ワークフロー(日次)

親エージェントは以下の順でサブエージェントに委譲する:

1. `recorder` … 前日の Obsidian 判断ログを読み、文脈を把握(任意・Phase 5)
2. `data-fetcher` … J-Quants から対象データを取得 → `data/raw/` に保存
3. `data-analyst` … 指標計算・可視化 → `data/processed/` に保存
4. `invest-analyst` … 戦略ルール(`strategies/`)に基づきシグナル判定・簡易BT
5. `reporter` … 結果を整形し、`scripts/notify.sh` 経由で Discord に通知 + `reports/` に保存
6. `recorder` … 今日の判断・根拠を Obsidian に記録(Phase 5)

## サブエージェント一覧

`.claude/agents/` に定義:
- `data-fetcher` — データ取得専門
- `data-analyst` — 指標計算・可視化専門
- `invest-analyst` — シグナル判定・バックテスト専門
- `reporter` — レポート整形・Discord通知専門
- `recorder` — Obsidian記録専門

## 重要な制約

- `.env` の認証情報を**ログやレポートに出力しない**。
- 外部への投稿(Discord)は `scripts/notify.sh` 経由のみ。意図しない宛先に送らない。
- 自動売買・発注は**行わない**(分析と通知・記録まで)。
- 破壊的なファイル操作(削除・上書き)は対象を確認してから行う。
